# База вертикальных спорт-видео

Единая база референсов-роликов (вертикаль 9:16, YouTube Shorts) под видео-анонсы «Лига Ставок».
Собрано через **ego lite (ego-browser)** поиском по YouTube, метаданные — через YouTube oembed.

- **Дата сборки:** 2026-08-26
- **Источник:** YouTube Shorts (поиск ego lite) + oembed (канал/заголовок)
- **Файл базы:** `videos.csv` (открывается в Google Sheets / Excel; фильтруется grep)

## Публичный доступ (открывается из любой сети)

- **Страница (поиск/фильтры):** https://vankastor.github.io/sport-verticals-db/
- **API (JSON, CORS `*`):** https://vankastor.github.io/sport-verticals-db/videos.json

Хостинг — GitHub Pages (репозиторий `vankastor/sport-verticals-db`). Обновление:
правим `videos.csv` → `python3 build_page.py` → `git add -A && git commit && git push`.
Через ~1 минуту Pages пересобирается.

**Пример использования API:**
```bash
curl -s https://vankastor.github.io/sport-verticals-db/videos.json | jq '.[] | select(.sport=="tennis")'
```

> В `api/videos.js` лежит serverless-версия API с фильтрами `?sport=&source_type=&q=&limit=`
> (для Vercel/Node). На GitHub Pages она не исполняется — Pages отдаёт статический
> `videos.json`, а фильтрация делается на странице/на стороне клиента.


## Колонки

| Колонка | Значения | Описание |
|---|---|---|
| `id` | число | Уникальный номер записи |
| `sport` | football / hockey / tennis / basketball / cs / boxing / mma / muaythai / f1 / dota2 / lol / valorant | Вид спорта |
| `subject_type` | team / player / generic | Что в центре: команда, игрок или общий момент |
| `subject` | текст | Название команды или имя игрока |
| `style` | celebration, action, goal, skills, dunk, entrance, emotion, slowmo, knockout, punch, highlights (через `;`) | Тип момента |
| `source_type` | official / broadcaster / fan | Тип канала-источника |
| `verified` | eye / meta | `eye` = просмотрено глазами, `meta` = по метаданным (заголовок/канал) |
| `title` | текст | Заголовок ролика |
| `channel` | текст | Канал-источник |
| `url` | ссылка | Прямая ссылка `youtube.com/shorts/…` |
| `batch` | текст / пусто | Метка партии для фильтрации: пусто у старых 221 записей, `20260826-match` — партия «подписанные матчи» (id 222+) |

## Как искать (примеры)

```bash
# Все клипы по футболу
grep ',football,' videos.csv

# Только официальные источники (чистый кадр под гифку)
grep ',official,' videos.csv

# Конкретная команда
grep 'Arsenal' videos.csv

# Конкретный игрок
grep 'Mbappe' videos.csv

# Эмоциональные крупняки (празднование/эмоция)
grep 'celebration\|emotion' videos.csv

# Хоккей + официальные каналы
grep ',hockey,' videos.csv | grep ',official,'
```

В Google Sheets: File → Import → загрузить `videos.csv` → включить фильтр по колонкам
`sport`, `subject`, `source_type`.

## Легенда качества

- `source_type=official` + `verified=eye` — максимально чистый исходник (нет фан-надписей).
- `source_type=fan` — фан-эдит: почти наверняка есть текст/музыка/вотермарка поверх кадра.
  Годится как референс движения/эмоции, но НЕ как чистый исходник под гифку.
- **Counter-Strike:** это игровой геймплей → HUD/killfeed всегда в кадре (без графики невозможно);
  для CS official = официальные турнирные/командные каналы (BLAST, ESL, NAVI CS2).
- **Теннис** — индивидуальный спорт: `subject` = игрок, «команда» неприменима.
- **Единоборства** (boxing/mma/muaythai) — индивидуальные: `subject` = боец или пара «X vs Y».
  Хайлайты часто с графикой/логотипами промоушена; `official` = каналы промоушенов/бойцов
  (UFC/PBC/ONE/Team Pacquiao), slo-mo — приоритет. Все записи — реальные проф-бойцы/бои.
- **Киберспорт** (dota2/lol/valorant) — берём НЕ голый геймплей, а ЭМОЦИЮ: реакции игроков/зала,
  слёзы, подъём трофея, празднования, клатч-камбэки (камера на людей). HUD/оверлеи турнира почти
  всегда в кадре — это ОК для эмоционального референса; `official` = каналы турниров
  (PGL/LoL Esports/VALORANT Champions Tour). Все записи — реальные проф-игроки/команды/турниры
  (TI, Worlds, VCT). **Counter-Strike** (`cs`) вынесен отдельным видом — эти 11 записей его не касаются.

## Партия «чистый кадр» (id 126–195)

Запрос Ивана: «докинь по 10 видео для футбола, баскетбола, хоккея, ufc, формулы 1, тенниса, доты —
без надписей и логотипов». Добавлено 70 записей (по 10 на вид), новый вид **`f1`** (Формула 1),
ufc записан в существующий `mma`. Отбор смещён к чистому кадру: приоритет **slo-mo / cinematic /
official / no commentary**, отсев фан-эдитов с наложенным текстом/ватермаркой и любителей.

- **Честность проверки:** «нет надписей/логотипов» окончательно подтверждается только просмотром.
  По ≥1 клипу на каждый вид проверено глазами через скриншот shorts-плеера (`verified=eye`, всего 12
  новых); остальные — `verified=meta` (по заголовку/каналу), их стоит досмотреть глазами перед продом.
- **Неизбежные логотипы:** спонсоры на форме/машине/бортах и арена-брендинг в живом матче остаются
  в кадре (убрать нельзя) — это НЕ наложенная графика. Критерий «чисто» = нет добавленного
  редакторского текста/титров/ватермарки/счёт-плашек поверх картинки.
- **F1:** отсеяны AI-сгенерированные ролики и эдиты с текстом; оставлены реальные съёмки
  (official Mercedes, бортовые, cinematic).
- **Dota 2 в этой партии:** cinematic/CGI (hero visualizer, cinematic movie) — чистые; клипы
  геймплея неизбежно с HUD/оверлеями (для доты чистого геймплея не бывает) — помечены честно.

## Партия «бокс + дота, только чистые» (id 196–221)

Запрос Ивана: «сделай еще для бокса и для доты по 15 видео, без надписей и логотипов». В отличие от
партии выше, здесь **каждый** ролик проверен глазами через скриншот shorts-плеера — оставлены только
клипы БЕЗ наложенного текста/титров/ватермарки/reaction-cam (`verified=eye` у всех 26).

- **Реальный выход:** бокс **12**, дота **14** (не по 15). Причина — честный отсев: поле Shorts
  массово засорено. По боксу отсеяно ~2/3 кандидатов (подписи с именами бойцов, ватермарки каналов,
  кнопки Subscribe, а также ролики ММА/кикбокса и любительский спарринг — берём только реальных
  профи). По доте отсеяны клипы с хиро-титрами и записи геймплея с HUD.
- **Бокс:** чистые = ринг-съёмка без подписей (TrillerTV/FCC слоу-мо, классика Ali/Tyson/Frazier/
  Pacquiao в чистом кадре, Matchroom replay-in-slow-mo). Неизбежная арена/бродкаст-графика (HBO,
  Matchroom, спонсоры ринга) остаётся — это не наложенный редакторский текст.
- **Дота:** чистые = hero visualizer / persona-intro / short film / CGI-cinematic без хиро-титров
  (Dota Cinematic Universe, AncientFramesKing, MidasMITTY, MOSIKA, Timeless и т.п.).
- Догнать до 15/15 можно, но только либо сняв критерий «без текста» (тогда войдут клипы с подписями),
  либо продолжив копать — по чистому кадру это потолок на текущем поиске.

## Партия «подписанные матчи» (id 222–228, batch=`20260826-match`)

Запрос Ивана: «нужно еще больше видео для хоккея, тенниса, футбола, баскетбола. сразу подписывай
матч (кто с кем играет). фильтруй только те, что без искажений, надписей, лого, знаков. выдели новые,
чтобы их можно было отфильтровать». Добавлены **колонка `batch`** (у старых 221 — пусто, у новых —
`20260826-match`) и **подпись матча** в `subject` = «Команда A vs Команда B» (в теннисе «Игрок vs Игрок»).

- **Каждый ролик проверен глазами** (скриншот shorts-плеера) на отсутствие наложенного текста/титров/
  ватермарки и растяжки (`verified=eye` у всех 7). Неизбежная арена/бродкаст-графика (спонсорские борта,
  мелкий бродкаст-бэйдж лиги, лого на форме) остаётся — это не наложенный редакторский текст.
- **Реальный выход: 7** — хоккей 2, футбол 2, баскетбол 2, теннис 1 (не по 10). Причина — честный отсев:
  пересечение «чистый кадр + подпись матча (кто с кем) + без наложенного текста» очень узкое. Массово
  отсеяны фан-эдиты с титрами/статами поверх кадра («68 KM/H», «CRAZY RALLY…», «SLEDGEHAMMER»),
  сплит-скрины с лого лиги, ватермарки каналов, леттербокс/растяжка, а также клипы, где матч
  не идентифицируется (нельзя подписать «кто с кем»).
- **Теннис — самый узкий:** чистые слоу-мо в теннисе почти всегда одиночный игрок (подача/удар) без
  соперника в кадре → подписать «A vs B» нельзя. Чтобы набрать больше тенниса/баскетбола, нужно либо
  ослабить требование «кто с кем» (разрешить подпись одного игрока), либо продолжить копать.
- **Матчи в партии:** Capitals vs Kings (Ovechkin #816), Oilers vs Stars (McDavid), Alcaraz vs Arthur Fils,
  Liverpool vs Man United (Gakpo), Arsenal vs Nottingham Forest (Zubimendi), Mavericks vs Pelicans (Luka),
  Westbrook vs Pelicans.

## Пополнение

Формат строки CSV: поля с запятыми (заголовки/каналы) — в двойных кавычках. Дедуп — по video id
(часть url после `shorts/`). Новые прогоны добавляются новыми строками с инкрементом `id`.
Фильтр новой партии: `grep ',20260826-match$' videos.csv` (или по колонке `batch` в Sheets/JSON).
